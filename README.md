\# Copy Checker



一个在浏览器中运行的文案长度检查器，帮助检查短文案的字符数量，并在超出字数限制时给予超限提示。



\## 功能



\- 实时统计字符数量，包含空格、标点和换行。

\- 显示还可输入多少字符，或已经超出多少字符。

\- 超限时提示变红，恢复到上限以内时变回黑色。

\- 支持一键清空，并继续输入。



\## 使用方法



1\. 在仓库页面点击 Code，再选择 Download ZIP。

2\. 解压下载的文件。

3\. 用浏览器打开 docs 文件夹中的 lesson01.html。

4\. 输入文案，查看字数和超限提示。



\## 当前说明



\- 当前上限为 12 个字符，是学习演示用的设定。

\- 暂未提供文案保存功能。

\- 部分组合表情可能被计为多个字符。
