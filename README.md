# Copy Checker



一个在浏览器中运行的文案长度检查器，帮助检查短文案的字符数量，并在超出字数限制时给予超限提示。



## 在线使用



[打开 Copy Checker](https://guaaha.github.io/copy-checker/)



## 功能



* 实时统计字符数量，包含空格、标点和换行。
* 显示还可输入多少字符，或已经超出多少字符。
* 超限时提示变红，恢复到上限以内时变回黑色。
* 支持设置1–10000之间的整数字符上限，点击“更新上限”后生效；无效输入会显示提示并保留最近一次有效上限。
* 支持一键清空文案并继续输入，保留已设置的字符上限。



## 下载到本地使用



1. 在仓库页面点击 Code，再选择 Download ZIP。
2. 解压下载的文件。
3. 用浏览器打开 docs 文件夹中的 index.html。
4. 输入文案，查看字数和超限提示。
5. 如需更改上限，在“字符上限”输入框中填写1–10000之间的整数，然后点击“更新上限”。



## 当前说明



* 默认上限为12个字符，可在页面中修改；刷新或重新打开页面后恢复为12。
* 暂未提供文案保存功能。
* 部分组合表情可能被计为多个字符。
